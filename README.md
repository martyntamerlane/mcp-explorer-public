# mcp-explorer-public

The published build of **MCP Explore** — a static web app that connects to an MCP server
directly from your browser and shows its tools, resources and prompts.

**Live site:** https://martyntamerlane.github.io/mcp-explorer-public/

## What is in this repository

Build output only: `index.html`, hashed JavaScript and CSS under `assets/`, the fonts and images
they reference, and `build.txt` — the source commit this build came from, which the release
process reads back from the live address to confirm the change is actually being served. Every file here is generated. Nothing is edited by hand, and the history
is replaced on each release rather than appended to, so this repository mirrors the current
build and is not a record of how it was made.

The source is kept in a separate private repository.
